# AI Agent Maintenance Rules

- Never delete existing content unless explicitly requested.
- Never redesign unrelated parts of the site.
- Modify only files necessary for the requested task.
- Do not install or remove dependencies without explicit permission.
- Do not modify build configuration unless explicitly requested.
- Do not modify Git history.
- Do not run destructive commands.
- Do not deploy automatically.
- Do not modify files outside this project directory.
- Preserve existing content and layout unless explicitly requested.
- Before large structural changes, explain the intended changes first.
- For content updates, prefer editing data or content files rather than structural code.
- If uncertain, ask rather than making broad assumptions.
